    Use it in your bot

    Everything on this page is plain JSON you can fetch from a Discord bot or anything else. No key needed, it refreshes after each race, and please cache it rather than fetching on every message.

    • /data/trivia/facts.json facts, each with an id, category, text and a link back to the data
    • /data/trivia/quiz.json questions, each with q, four options, the answer index, an explain line, category and difficulty
    • /data/trivia/onthisday.jsonraces by date, keyed "MM-DD", newest first
    const base = 'https://parc-ferme.pages.dev';
const { questions } = await (await fetch(base + '/data/trivia/quiz.json')).json();
const q = questions[Math.floor(Math.random() * questions.length)];

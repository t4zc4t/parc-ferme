    Use it in your bot

    Everything on this page is plain JSON you can fetch from a Discord bot or anything else. No key needed, it refreshes after each race, and please cache it rather than fetching on every message.

    • /data/trivia/facts.json facts, each with an id, category, text and a link back to the data
    • /data/trivia/quiz.json questions, each with q, two or four options, the answer index, an explain line, a table of the numbers behind it, a link, category and difficulty, plus a track svg path and an image link to a PNG of the outline for "which circuit is this" questions
    • /data/trivia/onthisday.jsonraces by date, keyed "MM-DD", newest first
    • /data/trivia/daily.jsona question of the day, keyed "YYYY-MM-DD" (UTC), set two weeks ahead, the same for everyone
    • /data/og/races/2026/<round>.pnga 1200 by 630 result card for each race this season, and /data/og/drivers/<id>.png for each driver, ready to post as an embed image
    • /data/feed.jsonwhat just happened: new qualifying, sprint and race results, provisional or official, with what changed when the official result lands
